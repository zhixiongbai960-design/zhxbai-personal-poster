# 照片处理与微调

## 先找清晰来源

检查用户指定目录、当前海报素材和已授权的其他个人物料。比较眼镜、眉毛、发丝、牙齿与衣领，而非只比较文件大小。保留原文件，新文件使用版本化名称。

## 清晰化的两种路径

- 如果当前环境有生图工具，用户授权后可做保守修复。提示词应把原图标为编辑对象，要求只改善模糊、压缩和噪声，保持脸型、眼距、眼镜、鼻口、发型、肤色、年龄、姿势和服装。不得把锐化需求扩大为换脸或美容。生成后与原图并排检查；发现身份漂移就换更清楚的来源或采用保守处理。
- 用户允许 Python 图像处理时，可用 `python scripts/enhance_portrait.py INPUT OUTPUT`。需要 Pillow，默认是半径 0.8、强度 70%、阈值 3 的轻度反锐化遮罩。它改善局部对比，不构造缺失的五官纹理。脚本拒绝覆盖原图，不做默认放大。

环境是否允许程序处理照片，以当前宿主及用户指令为准。无法可靠修复时明确说明限制，不把插值放大说成恢复高清。

## 位移与视觉边界

用 1080×1440 的设计坐标记录 `x/y/width/height`。向右移动 `dx>0`，向下 `dy>0`；导出尺寸变化时等比例换算。

例如上次 `x=420 → x=300`，位移为 `-120`。用户说“往右回去一半”，新坐标应是 `360`。只回调位移，照片尺寸、清晰化资产、裁切和其他内容保持原样。若上次没有记录位移，先从保留的源文件中核对，不能凭印象补数值。

`poster.py move --undo-fraction 0.5` 读取状态文件中最后一次移动，添加它的反向半程，保留完整轨迹。如果上次只有尺寸变化而无位移，不能假装这是位置回调。

图片 CSS 外框不等于人物轮廓。照片内自带留白、渐变蒙版和衣服亮度都影响视觉右缘。每次移动后检查人物、文字与参考卡片之间的实际空隙。
